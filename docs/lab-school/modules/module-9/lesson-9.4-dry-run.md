# Lesson 9.4: Dry run

Module 9: Capstone and demo

## Concept
A full rehearsal of the demo, end to end, including handling a curveball question. The point is to
have run it cleanly at least once, so the real presentation is smooth and you can recover gracefully
when something unexpected comes up. Practice is what turns a working pipeline into a confident demo;
the build earns the material, the rehearsal earns the delivery.

## Why it matters
"I have rehearsed the demo end to end, including a curveball, so the real presentation is smooth and
recoverable."
