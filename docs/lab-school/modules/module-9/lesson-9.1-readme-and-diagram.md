# Lesson 9.1: README and diagram

Module 9: Capstone and demo

## Concept
The capstone README ties everything together: an architecture diagram showing the data flow (FHIR to
bronze to silver to gold to dashboard) and the homelab to cloud mapping table. One picture should
convey the whole system. A reader should grasp what the pipeline does and how each homelab tool maps
to its Microsoft Fabric or Azure equivalent in well under a minute, before reading a single line of
code.

## Why it matters
"I can present the whole system in one diagram and a homelab to cloud mapping, so a reader grasps it
at a glance."
