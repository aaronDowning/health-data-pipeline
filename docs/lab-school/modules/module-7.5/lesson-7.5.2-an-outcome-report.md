# Lesson 7.5.2: An outcome report

Module 7.5: Analytics dashboard

## Concept
Build one concrete quality or outcome report: a view a non technical stakeholder could read and act
on, like a count of encounters by condition or a data completeness summary. The skill is framing the
data so the so what is obvious, with no jargon and no SQL required of the reader. This is the
stakeholder facing deliverable that the entire pipeline exists to produce, and it is where the dual
explain back habit pays off.

## Why it matters
"I can build a stakeholder ready outcome report, framing data so the takeaway is obvious to a non
technical reader."
